# About ODE: 
## App link: https://odeinterface.com
## Download page: https://odeinterface.com/download

ODE is a cross-platform desktop app built with Electron.js (Javascript), aimed at boosting productivity for multitaskers suited for everyone looking to build up their productivity
be it students, professionals, artists, researchers or engineers.

If you're tired of switching windows to query AI or capture notes, ODE let's you minimize the hassle.
ODE keeps everything seamless and offline.
It features a split-view interface: controls on one side, web content (e.g., ChatGPT) on the other, with persistent sessions.
No extra installs needed – all tools bundle in, running on Windows, Linux. For mac os builds, please see the downloads page: https://odeinterface.com/download
Perfect for quick captures without disrupting your flow!

Major Features:

- Multi-Display Screenshot: Select a screen, drag to crop a region, and copy to clipboard instantly – ideal for equations or diagrams.
- Offline Voice Transcription: Record from mic or system audio using Vosk AI; real-time editable popup, save to file, with permission handling.
- Easy Packaging: Builds to AppImage/deb/rpm (Linux), DMG (macOS), NSIS/portable (Windows) via electron-builder.
- Tray Integration: Minimize to system tray, with quick access to screenshots and toggles.
- Customizable Settings: Adjust main page URL, always-on-top mode, and more for personalized use.
